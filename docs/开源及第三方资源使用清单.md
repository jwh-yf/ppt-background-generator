## 3. 软件依赖清单

完整逐包清单（版本、许可证、**许可证判定依据**、依赖层级、用途）见
`docs/Dependency_Licenses_Generated.md`，由 `tools/gen_license_table.py` 从当前环境的
`dist-info` 直接生成。要点：

- **共 48 个发行包**，其中直接依赖 17 个、传递依赖 31 个。
- 全部包的许可证都可以从包元数据（`License-Expression` / `Classifier`）或包内 `LICENSE` 文本判定，
  **没有 UNKNOWN**。
- 主要许可证分布：Apache-2.0（diffusers、transformers、accelerate、safetensors、huggingface_hub、
  tokenizers、peft、regex、requests 等）、BSD 系（torch、torchvision、numpy、Pillow 为 MIT-CMU、
  lxml、networkx、sympy 等）、MIT（python-pptx、PyYAML、filelock、urllib3 等）、
  MPL-2.0（tqdm、certifi，仅在文件级 copyleft 范围内）。
- **没有任何 GPL/AGPL/LGPL 代码被链接进本作品**（`setuptools` 的元数据声明为 MIT；
  其内部 `_vendor` 目录含 LGPL 组件，但 `setuptools` 只在安装期使用，不参与作品分发与运行）。
- 关键义务（已履行）：
  1. 保留所有包的版权声明与许可证文本 → 随提交材料附 `docs/Dependency_Licenses_Generated.md`
     与 `artifacts/dependency_licenses.json`；
  2. Apache-2.0 的 NOTICE 传递 → 未修改这些库，无衍生 NOTICE 需要合并，随附声明即可；
  3. 未使用任何库的商标做宣传。

## 4. Stable Diffusion v1.5 的 CreativeML OpenRAIL-M：义务与履行

这是本作品**唯一**带使用限制的开放权重，因此单列一节说明。

| OpenRAIL-M 要求 | 本作品的履行方式 | 证据 |
|---|---|---|
| 随附许可证全文 | 许可证随权重一并保留在项目内，并在提交材料中指明路径 | `tools/hf/stable-diffusion-v1-5/README.md`（含许可信息）、本文件 |
| 传递使用限制（下游同样受 §II 限制） | 在本文件与 `docs/设计说明.md` 中明确声明，并随作品一并提供 | 本节 + §6 |
| 不得用于 §II 列出的用途（违法、伤害、虚假信息、医疗/法律等专业建议替代等） | 作品用途限定为「生成演示文稿背景图」；网页界面与文档均声明该限制 | 网页页脚提示、本文件 |
| 不得移除/规避技术限制 | 未做任何规避；保留原 `safety_checker` 配置 | 未修改基座权重 |
| 署名与版本可追溯 | 记录 repo_id、下载来源、字节数与校验信息 | `artifacts/model_manifest.json` |

复现者需自行从公开来源获取基座并遵守同一许可证。这一选择同时降低了分发风险与作品体积。

**使用了公开实现的部分（用于对照，非作品主体）**

- `peft` 仅用于评测里**加载** LoRA 适配器做消融对照；训练循环本身不依赖它。
- `diffusers` 提供 UNet/VAE/调度器的**结构与加载**；本作品自研的是数据、训练循环、
  约束后处理与整个应用层。

**没有做的事（如实声明）**

- 没有修改、patch、fork 任何第三方库的源代码；
- 没有把第三方库的代码复制进本仓库；
- 没有使用任何第三方预训练 LoRA、ControlNet、IP-Adapter 等权重。

**本作品自身产出的许可证（开放成果）**

本作品的开放成果分三类，许可证不同——分开写是为了让复用者一眼看清边界，
而不是笼统地说一句"开源"。

| 产出 | 位置 | 许可证 | 复用者需要做什么 |
|---|---|---|---|
| 源代码 | `app/`、`data/`、`train/`、`eval/`、`tools/` | **MIT**（仓根 `LICENSE`） | 保留版权与许可声明即可商用、修改、再分发 |
| 数据集（600 张合成背景 + 108 张母图 + 标注 JSONL） | `data/dataset_v1/`、`data/assets/`、`data/splits/` | **CC BY 4.0** | 使用时署名「pptbg 团队」；可商用、可改、可再分发 |
| LoRA 适配器权重 | `train/runs/*/checkpoint-*/adapter_model.safetensors` | **CreativeML OpenRAIL-M** | 必须同一许可证再分发、传递基座的使用限制（见 §4） |

第三行是**必须的从属关系**，不是我们的选择：适配器是 Stable Diffusion 1.5 的衍生作品，
其许可证允许分发衍生权重，但要求沿用同一份条款。把适配器改标成 MIT 会与基座许可证冲突，
因此这里明确写 OpenRAIL-M —— 这也是本作品"权利边界清晰"的具体含义：
代码宽松、数据可复用于训练、权重跟着基座走。

## 7. AI 生成内容与工具使用声明

按规则手册要求，对「AI 生成内容」与「AI 辅助工具」分别声明：

1. **作品本身的 AI 成分**：本作品的**输出图像由模型生成**（SD1.5 + 自研 LoRA），
   训练数据由**确定性程序**合成（不是模型生成）。输出图像属于 AI 生成内容，
   **不主张其作为"团队自主知识产权"**；团队主张的是代码、数据集、训练配置与评测方法。
2. **开发过程使用的 AI 辅助工具**：开发过程中使用了大模型辅助编程工具协助撰写代码与文档。
   团队对所有提交内容负责：每一个脚本的输入输出、每一个数字都可按 §8 重跑复核，
   关键结论（数据集体检、评测指标）均由本仓库脚本产出而非工具描述。
3. **未使用 AI 生成任何参赛身份的证明材料**。

## 8. 可复核性：每个结论怎么重跑

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
. .\env.ps1

# 依赖清单（版本号与许可证判定的来源）
pptbg tools\gen_license_table.py --out docs\Dependency_Licenses_Generated.md --json artifacts\dependency_licenses.json

# 权重清单（含字节数与下载来源）
pptbg tools\fetch_model.py sd15        # 已完整时只做校验，不重复下载
type artifacts\model_manifest.json

# 数据集与溯源
pptbg data\make_backgrounds.py --assets data\assets\manifest.jsonl --out data\dataset_v1 --count 600 --seed 20261016
pptbg data\validate_dataset.py --records data\dataset_v1\records.jsonl --images-root data\dataset_v1\images --out data\dataset_v1\report

# 评测
pptbg eval\run_eval.py --prompts eval\prompts_v1.jsonl --out eval\results

# 端到端
pptbg app\smoke_test.py
```

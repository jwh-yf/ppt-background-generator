# 演示视频分镜脚本（方案 B：无声录屏 + 后期字幕）

> 手册要求：**MP4，3–5 分钟，≤300 MB**，原则上须提交。
> 这一项在「实现完成度与可验证效果」25 分里权重最大——评委看不到你本机，只能看到这段视频。
>
> **本方案的分工**：你只负责「按顺序点鼠标」，全程不用开口；字幕、节奏、转场由我后期加。
> 目标是 **3 分 45 秒**（留 75 秒余量到 5 分钟上限）。

## 一、录制前 15 分钟的准备（照着做，别跳）

1. **起服务并跑热**：
   ```
   pptbg app\server.py --port 8763
   ```
   浏览器打开 <http://127.0.0.1:8763/>，先随便生成一张——首张要 20 秒加载模型，别把这个等录进视频。
2. 浏览器 `F11` 全屏，缩放 100%（`Ctrl+0`），关掉书签栏（`Ctrl+Shift+B`）。
3. **关掉会泄露身份的东西**：微信/QQ 弹窗、桌面文件名、窗口标题里的 `C:\Users\<你的名字>\...`。
   录制时把浏览器窗口最大化，窗口标题只露 `127.0.0.1` 就没问题。
4. 把 `submission\video\assets\` 这个文件夹在资源管理器里打开，按 `01…06` 排序好，**用 Windows 照片应用逐张全屏打开**（选中后按 `Enter`，`←/→` 翻页）。
5. 录制工具：**`Win + G`**（Xbox Game Bar，系统自带）→ 点录制按钮；或 PowerPoint「录制屏幕」。
   录完的文件在 `视频\捕获` 文件夹，扩展名 `.mp4`。
6. 关掉输入法的中文状态（录制时不要出现候选词框）。

## 三、录制时唯一要注意的三件事

1. **只录一次，中间不要停**。录长了比录短了好——多出来的部分我可以剪，缺的补不了。
2. **鼠标慢一点**。录制时鼠标移动速度在成片里会显得更快；每次点击前停 0.5 秒。
3. **第 2 段不要出现加载转圈超过 3 秒**。如果卡住，重录这一段即可（其余段不受影响）。

## 四、三条不能犯的错

1. **别只放好看的图**。评分表里「明确创新」和「模型调用」的差别，就在于评委会不会觉得你只是套了个壳。第 6 段那张对照就是回答这个问题的，不许剪掉。
2. **别让画面出现没做过的事**。视频里每个数字都必须能在技术报告里搜到同一处：`6.43`、`16.05`、`100%`、`75%`、`0.37%`、`1.33%`。
3. **别超过 5 分钟**。

## 五、录完自检

- [ ] 时长 3–5 分钟，MP4，体积 ≤300 MB
- [ ] 画面里没有学校名、姓名、邮箱、`C:\Users\...` 路径
- [ ] 第 2 段能看到「生成 → 三视图 → 下载」完整链路
- [ ] 第 3 段能看到在 PowerPoint 里真的改了字
- [ ] 上传网盘后，用**无痕窗口**打开链接确认评委能看

## 六、录完之后

把那个 `.mp4` 放进 `submission\video\`，告诉我文件名即可。后面四步我来做，工具已经就绪并实测通过：

1. 烧硬字幕（`tools\burn_subs.py`，ffmpeg 7.1 + libass，中文字幕已实测正常）
   ```
   pptbg tools\burn_subs.py --video submission\video\<你的文件>.mp4 ^
                            --srt   submission\video\字幕.srt ^
                            --out   submission\video\成片.mp4
   ```
   字号默认 12（libass 按 PlayResY=384 缩放，1080p 下实际约 38px）；超 300 MB 就把 `--crf` 调大。
2. 对时轴：你的实际操作节奏和 `字幕.srt` 不会完全一致，我按画面内容重新对齐，必要时拆句。
3. 加 3 秒片头（作品名 + 一句话）与 2 秒片尾（开源仓库地址占位）。
4. 先给你一版预览，确认后再替换 `submission\04_演示视频.mp4`。
